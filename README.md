## 📖 项目介绍

ETRI (Electronic Trade Risk Index) v3.0 是一个面向跨境贸易的全链路风险评估智能系统，覆盖**货物贸易、数字贸易、服务贸易**三大业务场景，支持**9 大目标市场 × 13 个子行业**的穿透式风险量化。

### 核心能力

| 能力 | 说明 |
|------|------|
| **双层评估模型** | CTRI 贸易风险评估 + PRS 支付风险评估，层间联动权重动态调整 |
| **EPIC 四维对标** | E-金融风险、P-地缘政治、I-物流供应链、C-合规制裁（货物贸易）；数字主权、金融支付、知识产权、网络安全（服务贸易） |
| **FCE-AHP 动态权重** | 基于模糊综合评价 + 层次分析法的组合赋权，VIX/CDS/地缘事件触发权重切换 |
| **13 子行业穿透** | 电子/半导体、汽车、新能源、手机游戏、SaaS、跨境电商等，行业差异化风险因子 |
| **风险传导分析** | 桑基图可视化贸易层→支付层风险传导路径，量化传导贡献度 |
| **量化损失测算** | 瀑布图展示汇兑损失、DST、支付处理费、拒付成本、合规成本五大损失项 |
| **全球风险热力图** | 9 大区域实时风险快照，CDS/VIX/OFAC/SPI 综合评分 |

```bash
# 方式一：直接打开

cd CTRI_风险评估
```

## 📚 技术文档：方法论说明

### 1. EPIC 四维对标框架

EPIC 是专为货物贸易设计的风险评估框架，四个维度覆盖跨境贸易核心风险源：

| 维度 | 全称 | 权重 | 核心指标 |
|------|------|------|----------|
| **E** | Economic/Financial Risk | 35% | CDS利差、VIX恐慌指数、汇率波动率、布伦特原油、CRB商品指数 |
| **P** | Political/Geopolitical Risk | 20% | 地缘事件累计评分、OFAC制裁状态、霍尔木兹海峡风险 |
| **I** | Infrastructure/Logistics Risk | 15% | BDI波罗的海干散货指数、港口效率、航运成本 |
| **C** | Compliance/Sanctions Risk | 20% | OFAC实体清单、SPI制裁压力指数、BIS出口管制 |
| **ESG** | ESG Risk | 10% | EUA碳配额价格、CBAM碳关税、极端天气事件 |

> **学术支撑**：EPIC框架对标全球采购风险指数（Proxima×Oxford Economics, 2025）和Coface 2026国家与行业风险手册（覆盖160经济体×13行业），行业风险分布参考 Allianz Trade Sector Atlas (2025)：中等风险45%、敏感43%、低风险仅9%。

### 2. FCE-AHP 动态权重机制

#### 2.1 基础权重（AHP 层次分析法）

采用 AHP 确定各维度基础权重，通过专家判断矩阵和一致性检验（CR<0.1）确保权重合理性：

```
货物贸易:  E(0.35) > P(0.20) = C(0.20) > I(0.15) > ESG(0.10)
服务贸易:  数字主权(0.30) > 金融支付(0.25) > 知识产权(0.20) > 人员签证(0.15) > 网络安全(0.10)
```

#### 2.2 模糊综合评价（FCE）动态调整

当外部环境指标突破阈值时，触发权重动态调整：

| 触发器 | 条件 | 权重调整 |
|--------|------|----------|
| 金融危机 | VIX > 30 | 金融/支付维度权重提升至 40-50% |
| 地缘冲突 | 地缘事件 > 200分 | 地缘/数字主权维度权重提升至 40-45% |
| 制裁升级 | OFAC制裁 + SPI > 60 | 合规/支付维度权重提升至 35% |
| 能源危机 | 布伦特 > $90 | 能源预警标记，持续监控 |

调整后执行归一化：`w_k = w_k / Σw`，确保权重之和为 1。

> **学术支撑**：CTRI指标体系构建基于 AHP+博弈论组合赋权+SCOR模型（张建侠, 安玉珠.《中国商论》2025第2期）；权重校准采用改进TOPSIS+损失惩罚方法（Shi et al., *Information Sciences*, 2025, JCR Q1）；不确定性指标处理采用 IndetermSoft Set 多准则决策（fs.unm.edu, 2025）。

### 3. 双层评估模型（CTRI + PRS）

#### 3.1 第一层：CTRI 贸易风险评估

```
CTRI = Σ(维度得分_k × 权重_k)    k = 1,2,...,5
```

每个维度得分基于多因子累加模型，因子权重由行业敏感度决定：

```
金融风险 = f(CDS, VIX, 汇率波动率, 布伦特原油, CRB指数)
地缘风险 = f(地缘事件评分, OFAC制裁状态)
合规风险 = f(OFAC, SPI, 行业出口管制等级)
物流风险 = f(BDI指数, 港口效率)
ESG风险  = f(EUA碳价, 行业碳敏感度)
```

#### 3.2 第二层：PRS 支付风险评估

```
PRS = 交易欺诈 × 35% + 合规制裁 × 35% + 汇率金融 × 30%
```

| PRS维度 | 核心因子 |
|---------|----------|
| 交易欺诈 | 拒付率、支付方式欺诈系数、友好欺诈增长趋势 |
| 合规制裁 | OFAC制裁、外汇管制等级、AML法规强度 |
| 汇率金融 | 汇率波动率、CDS利差、央行利率、油价传导 |

#### 3.3 层间联动权重（DTF 机制）

基于动态贸易融资（Dynamic Trade Finance）理论，ETRI 综合得分通过层间联动权重合并两层评估：

```
ETRI = CTRI × w₁ + PRS × w₂
```

| 场景 | w₁ (CTRI) | w₂ (PRS) | 触发条件 |
|------|-----------|----------|----------|
| 基准 | 0.40 | 0.60 | 无特殊触发 |
| 极端金融+制裁 | 0.25 | 0.75 | VIX>35 且 OFAC制裁 |
| 主权信用危机 | 0.30 | 0.70 | CDS>300bp |
| 战争/政变 | 0.50 | 0.50 | 地缘事件>300分 |
| 高DST数字贸易 | 0.55 | 0.45 | 数字贸易且DST≥10% |

> **学术支撑**：层间联动权重机制基于动态贸易融资DTF理论（Management Science / 中国人民大学, 2022）；坏账预警系统参考 World Bank Trade Finance Research 海关数据方法（可提前3-5个月识别）。

### 4. 量化损失测算模型

```
总损失 = 汇兑损失 + DST损失 + 支付处理费 + 拒付成本 + 合规成本
```

| 损失项 | 计算公式 | 参数说明 |
|--------|----------|----------|
| 汇兑损失 | 年交易额 × (波动率/100 × 0.28) | 0.28为新兴市场货币风险经验系数 |
| DST损失 | 年交易额 × DST税率 | 数字服务税为刚性成本 |
| 支付处理费 | 年交易额 × 支付方式费率 | 信用卡2.5%、应用商店20%、电汇1.5% |
| 拒付成本 | 年交易额 × (拒付率/100 × 1.5) | 1.5倍成本乘数含手续费和收入损失 |
| 合规成本 | 年交易额 × 2% | KYC/AML合规固定成本 |

### 5. 风险等级阈值

| 等级 | ETRI区间 | 含义 | 建议行动 |
|------|----------|------|----------|
| 🟢 绿色 | 0-30 | 低风险，各维度安全 | 常规监控 |
| 🟡 黄色 | 31-50 | 中等风险，部分维度预警 | 每月复核，针对性缓释 |
| 🟠 橙色 | 51-70 | 高风险，多维度预警 | 72h启动P0，每周复核 |
| 🔴 红色 | 71-100 | 极高风险，全面预警 | 暂停新增，每日监控 |

> 阈值锚定方法论参考 IndexBox (2026) 贸易风险响应触发机制框架。

## 🤖 Prompt Engineering：核心指令

以下为本项目构建过程中使用的核心 Prompt，展示了如何通过结构化 Prompt Engineering 驱动复杂风险评估系统的设计。

### Prompt 1：系统角色定义与任务框架

```
【ETRI全链路风险评估—一键执行】

角色：你是一名精通国际金融与跨境贸易风险量化的高级分析师。

任务：对指定跨境贸易场景执行ETRI v3.0全链路风险评估，输出完整量化报告。

评估框架：
- 第一层 CTRI（跨境贸易风险指数）：基于EPIC四维模型
  · E-金融风险：CDS利差、VIX恐慌指数、汇率波动率、大宗商品
  · P-地缘政治：地缘事件评分、OFAC制裁、霍尔木兹海峡风险
  · I-物流供应链：BDI指数、港口效率、航运成本
  · C-合规制裁：实体清单、SPI指数、出口管制
  · ESG：碳价、CBAM、极端天气

- 第二层 PRS（支付风险评估）：
  · 交易欺诈（35%）：拒付率、支付方式系数
  · 合规制裁（35%）：OFAC、外汇管制、AML
  · 汇率金融（30%）：波动率、CDS、央行利率

- 层间联动（DTF）：
  · 基准：CTRI×40% + PRS×60%
  · VIX>35+OFAC → CTRI×25% + PRS×75%
  · CDS>300 → CTRI×30% + PRS×70%

输出要求：
1. ETRI总分（0-100）+ 风险等级（绿/黄/橙/红）
2. 六维雷达图数据
3. 动态权重触发日志
4. 风险传导桑基图数据
5. VaR损益分析
6. 预期损失瀑布图
7. P0/P1/P2分级行动建议
```

### Prompt 4：风险传导与量化损失

```
设计风险传导分析和量化损失测算模块：

风险传导（桑基图）：
- 左侧：CTRI各维度风险源
- 右侧：PRS三个支付风险维度
- 连线宽度 = 传导贡献度
- 传导路径权重：
  · 合规制裁→支付合规 25%
  · 外汇管制→支付金融 20%
  · 数据本地化→支付合规 18%
  · 油价冲击→汇率金融 15%
  · 网络攻击→交易欺诈 12%
  · 央行鹰派→汇率金融 10%

量化损失测算：
- 汇兑损失 = 年交易额 × (波动率/100 × 0.28)
  · 0.28为新兴市场货币风险经验系数
- DST损失 = 年交易额 × DST税率
- 支付处理费 = 年交易额 × 费率
  · 信用卡2.5%、应用商店20%、电汇1.5%、信用证1%、赊销0.5%
- 拒付成本 = 年交易额 × (拒付率/100 × 1.5)
  · 1.5倍乘数含手续费和收入损失
- 合规成本 = 年交易额 × 2%

VaR计算：
- 90天1% VaR = 年交易额 × 0.005 × (波动率/10)
- 90天5% VaR = 年交易额 × 0.003 × (波动率/10)
```
